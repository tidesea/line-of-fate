## 字段说明

| 字段 | 含义 |
|------|------|
| cost | 部署费用 |
| maxHp | 生命上限 |
| move | 每回合移动格数 |
| minRange / maxRange | 攻击距离（格） |
| attack | 主攻击（远程优先） |
| meleeAttack | 近战攻击 |
| speed | 行动优先级相关速度 |
| counters | 反击次数 |
| size | 占地（宽×高，格） |
| power | 内部战力估算 |
| efficiency | power ÷ cost（性价比） |

### 战力公式（现行）

```
durability = maxHp × 0.32
offense    = attack × (1 + maxRange × 0.12)
mobility   = move × 3.5 + speed × 2
reaction   = counters × 7
footprint  = size 面积 > 1 时 ×0.9，否则 ×1
power      = round((durability + offense + mobility + reaction) × 能力系数 × footprint)
```

能力系数：平民 `0.8`；护卫 `1.1`；神射手 `1.18`；士兵 `1.15`；战车 `1.18`；特警 `1.28`；爬尸 `1.08`；腐尸 `1.12`；烟鬼 `1.1`；毒爆 `0.72`；猎手 `1.16`；憎恶 `1.12`；母体 `1.35`。
