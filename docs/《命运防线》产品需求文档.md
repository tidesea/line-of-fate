## 第一章 核心概念与产品定位

### 1.1 项目基础信息

- **产品名称**：《命运防线》（Line of Fate）
- **产品形态**：Web 端轻量化纯前端战棋游戏（无需后端、无数据库、打开即玩）。
- **目标受众**：喜欢《植物大战僵尸》、《英雄无敌3》、战棋/自走棋的策略向泛用户。
- **视觉美学**：
  - **风格**：2.5D 等轴测（Isometric）+ Q 版微缩模型（Low-Poly Toy-like）。
  - **基调**：色彩明快的高饱和废土风，消解末日题材的压抑与血腥感，营造轻松但烧脑的策略反差。
- **核心卖点**：
  - **双阵营深度差异化**：非换皮数值，人类打“阵地构建与后勤运营”，僵尸打“尸潮堆叠与自爆滚雪球”。
  - **伪卡牌 + 经典战棋博弈**：卡牌构筑决定“战场投放”，战棋走位决定“战术执行”。
  - **零资产依赖**：全角色与场景由 Three.js 程序化几何体动态装配，秒开无加载等待。

### 1.2 核心循环与用户心流模型

游戏通过“部署筹措 -&gt; 走性格局 -&gt; 目标争夺 -&gt; 战果沉淀”形成高度自洽的循环：

## 第二章 核心玩法机制与战斗底层模型

### 2.1 战术网格与空间规划

战斗发生在一个 **15 列 × 9 行（共 135 格）** 的虚拟矩形网格上：

- **人类部署缓冲区**：第 `0 ~ 1` 列（最左侧），人类新打出的卡牌只能在此两列的空置格具象化。
- **僵尸部署缓冲区**：第 `13 ~ 14` 列（最右侧），僵尸新打出的卡牌只能在此两列的空置格具象化。
- **中立交火与争夺区**：第 `2 ~ 12` 列，包含掩体阻挡、中央据点、幸存者驻地与空投箱。

### 2.2 终局判定：中央据点争夺战 (King of the Hill)

本游戏摒弃单纯以“全歼敌人”为唯一终局的单一设计，引入**中央据点（The Nexus）绝对控制权争夺**，提高战术博弈深度。

- **据点锚定位置**：固定于全图正中心 `Col: 7, Row: 4`。
- **占领与胜利机制**：
  1. 任意单位在行动结束时停留于该格，即激活该阵营的“占领计数器”，计为持续第 1 回合。
  2. 若该单位**连续驻留至第 5 个大回合结算**（相当于顶住对方 5 轮强攻），**该阵营直接获得终极战役胜利**。
- **严苛的重置规则（惩罚机制）**：
  - 若据点上的单位**自主移出**、**被外力位移**（民兵击退、憎恶钩爪）或**被击杀死亡**，**占领倒计时立即归零 (Reset to 0)**。
  - 友方替补单位踩入据点，必须从第 1 回合重新累计，不可继承上一单位的占领时长。

### 2.3 经典战棋（HoMM3 式）行动流与战斗公式

#### (1) 行动队列机制 (Initiative Queue)

- **大回合开始时**，系统收集场上所有存活单位，按其**速度（Speed）从大到小排列**，形成全局行动序列。
- 速度相同时，玩家方先动；若同属于一方，按网格从左到右、从上到下排序。
- 当所有单位均完成一次行动后，该大回合结束，进入大回合结算阶段。

#### (2) 距离与近战惩罚机制 (Distance &amp; Melee Penalty)

- 距离计算采用**切比雪夫距离（Chebyshev Distance）**：

  \$\$\\text{Dist} = \\max(\\vert{}x\_1 - x\_2\\vert{}, \\vert{}y\_1 - y\_2\\vert{})\$\$
- **远程单位贴脸惩罚**：
  - 当最大射程 \$\\text{MaxRange} &gt; 1\$ 的纯远程单位（如民兵、正规军、烟鬼尸）与目标距离 \$\\text{Dist} = 1\$（相邻）时，**攻击力直接扣减 50%**，且**攻击动作不会触发自身的主动战术特效**。
  - **豁免单位**：**猩红母体**（英雄单位）属于远近全能型，贴身爪击造成 100% 全额伤害；**装甲战斗车**免除近战惩罚，但由于最小射程为 2，无法将 1 格内的敌人作为主目标。

#### (3) 物理反击规则 (Counter-Attack)

- **触发前提**：受到近战攻击（\$\\text{Dist} = 1\$）、遭受攻击后存活、且本回合内剩余反击次数 \$&gt; 0\$。
- **反击结算**：

  \$\$\\text{反击伤害} = \\lfloor \\text{受击方基础近战攻击力} \\times 0.7 \\rfloor\$\$
- **反击次数**：默认各兵种每大回合仅有 **1 次**反击机会（武装平民等专属被动可额外增加）。受到远程武器攻击时，绝不触发反击。

## 第三章 阵营资源与经济动态系统

### 3.1 双轨制资源设计哲学

- **人类：补给点 (Supply Point)**

  战术目标为“守住阵线，减少战损”。人类补给有限且昂贵，兵种单兵造价高，防守反击与占领后勤点是运营核心。
- **僵尸：变异点 (Mutation Point)**

  战术目标为“尸潮推进，以战养战”。僵尸依靠兵种阵亡、生化吞噬与自爆获得养分，打法强调不计成本的前赴后继。

## 第四章 完整单位设计与数值平衡矩阵

### 4.1 人类先锋军 (Human Vanguard)

[武装平民] ──前排肉盾──► 挡刀 / 围殴 / 筑起第一道人墙

#### 1. 武装平民 (Civilian Militia)

- **消耗**：1 补给 | **生命**：45 | **移动力**：3 | **射程**：1 (近战) | **基础攻击**：12 | **反击次数**：2
- **被动技能【草木皆兵】**：自身反击次数 +1。网格周围 1 格内每存在一个人类友军，自身防御免伤提升 15%（最高可叠加至 45%）。
- **设计意图**：超低费防线填充者，适合抱团卡位，利用双次反击让僵尸炮灰付出双倍代价。

#### 2. 民兵护卫 (Local Guard)

- **消耗**：2 补给 | **生命**：30 | **移动力**：2 | **射程**：1\~3 格 | **基础攻击**：18 | **反击次数**：0
- **被动技能【霰弹压制】**：对相邻 1 格敌人伤害削减 50%。攻击 2 格距离的目标时，有 35% 概率将目标向后方直线**击退 1 格**（若目标身后有阻挡则无法击退）。
- **设计意图**：早期远程骚扰与控点工具，利用击退将敌方单位移出中央据点是其战略价值所在。

#### 3. 正规军士兵 (Infantry Soldier)

- **消耗**：4 补给 | **生命**：75 | **移动力**：3 | **射程**：1\~4 格 | **基础攻击**：32 | **反击次数**：0
- **被动技能【战术点射】**：对相邻 1 格敌人伤害削减 50%。若当前回合未发生移动而直接原地射击，本次射击无视目标 30% 防御且暴击率提升 40%（造成 1.5 倍伤害）。
- **设计意图**：阵地战的主力输出，架枪不动时杀伤极高，极度依赖前排平民建立保护圈。

#### 4. 装甲战斗车 (Armored Combat Vehicle)

- **消耗**：7 补给 | **生命**：220 | **移动力**：4 | **射程**：2\~5 格 | **基础攻击**：45 (AoE) | **反击次数**：1
- **占地体积**：2×1 网格（横向占 2 格）。
- **被动技能【20mm 链式机炮】**：以目标点为中心造成十字范围 5 格的溅射伤害（主目标 100%，边缘 50%）。免疫一切减速与感染 Debuff；不可被任何技能强制位移。
- **设计意图**：人类终极破局武器，清缴尸潮的绝对王牌，但惧怕贴脸缠斗（最小射程为 2，无法攻击相邻敌人）。

#### 5. 英雄单位：生化前线特警 (Bio-Hazard Specialist)

- **消耗**：6 补给 | **生命**：160 | **移动力**：3 | **射程**：1\~2 格 | **基础攻击**：28 | **反击次数**：1
- **主动技能【战地净化素】(冷却 2 回合)**：选定自身周围 2 格内的一个友军，清除其身上所有的感染与减速状态，并恢复 50 点生命值。
- **被动光环【阵线督导】**：特警存活时，全体人类单位移动力额外 +1。

#### 6. 缝合憎恶 (Abomination - 坦克型)

- **设计意图**：终极破坏者。能够强行将驻守在中央据点内的人类单位扯出据点，瞬间打断人类的 5 回合倒计时。

#### 7. 英雄单位：猩红母体 (Crimson Mother)

- **消耗**：8 变异 | **生命**：220 | **移动力**：3 | **射程**：近 1 / 远 2\~4 | **基础攻击**：近 30 / 远 26 | **反击次数**：1
- **核心被动【全能杀戮】**：近战不触发贴脸惩罚（100% 伤害），远程喷射毒液。击杀任意人类后，原地将其转化为 1 只爬行尸。
- **核心被动【生命繁衍】**：每个大回合结束时，母体身旁的空置格自动免费产出 1 只爬行尸。

## 第五章 状态异常与战术机制规范

```plaintext
Debuff / Buff 结算顺序：
[受到攻击] ──► 附加状态 ──► [轮到目标行动] ──► 扣除持续伤害 ──► [行动结束] ──► 计数器 -1

```

- **【感染 (Infection)】**：每回合受到持续伤害。生化特警的主动技能可彻底清除。
- **【瘫痪 (Stun)】**：跳过当前大回合的行动机会，不可移动、不可攻击，但保留被动反击权利。
- **【致盲浓烟 (Smoke Blindness)】**：处于烟雾格内的远程单位，攻击距离上限缩减 1 格，基础命中率下降。

## 第六章 敌对 AI 自动决策树与行为逻辑 (AI Behavior System)

为确保纯客户端单机体验具有足够的战术博弈感，游戏内置双阶段自主决策 AI。AI 在行动逻辑上严格模拟真人决策过程，涵盖“经济与兵种部署阶段”**与**“战棋走位及集火阶段”。

### 6.1 阶段一：AI 卡牌投放与部署决策 (Deployment AI)

AI 在每个大回合的部署阶段根据当前战场态势、剩余点数及空置部署格自动出牌：

```plaintext
[检查 AI 资源点数] ──不足最廉价兵种成本──► 跳过部署，进入战棋轮动
        │ 满足
        ▼
[中央据点是否有敌军在占领?] 
   ├── 是 ──► 优先检索手牌中具备克制/高机动/打断属性的兵种出战
   │          (僵尸优选: 暗影掠食者切后排 / 缝合憎恶拽人 / 毒爆尸炸点)
   │          (人类优选: 正规军远程狙杀 / 民兵击退)
   └── 否 ──► 走常规平衡部署逻辑：
              * 场上近战与远程比例 < 1:1 时：补充前排肉盾 (平民/腐尸)
              * 场上近战充足时：补充远程或功能兵 (民兵/烟鬼/毒爆)
              * 资源点 ≥ 6 点时：立即打出高阶战术单位 (战车/憎恶/英雄)

```

- **部署网格优选算法**：
  - AI 检查己方部署线（人类第 0\~1 列，僵尸第 13\~14 列）。
  - 优选 Y 轴对称靠近中央轴线（Row: 3, 4, 5）的空地；若被占满，则向上下两翼扩散（Row: 2, 6 -&gt; 1, 7 -&gt; 0, 8）。

### 6.2 阶段二：战棋轮动、寻路与集火规则 (Action AI)

当轮到具体某个 AI 单位行动时，遵循一套严格的优先级判定链，杜绝盲目冲锋与近战自废武功：

#### 1. 目标选择优先级 (Target Scoring)

AI 会为全场每一个敌方单位计算威胁与击杀分值 \$S\_{target}\$：

\$\$S\_{target} = W\_{hill} \\times P\_{hill} + W\_{killable} \\times P\_{killable} + W\_{threat} \\times P\_{threat} - W\_{dist} \\times \\text{Dist}\$\$

- **\$P\_{hill}\$（据点打断权重）**：若该敌方正站在中央据点上，分值极高（权重 100），AI 强制将其标记为**第一集火目标**，目的在于清空据点倒计时。
- **\$P\_{killable}\$（残血收割权重）**：若该目标当前血量低于本单位伤害输出（可直接斩杀），权重 50。
- **\$P\_{threat}\$（核心输出威胁）**：若目标为正规军、装甲车、毒爆尸等高伤兵种，权重 30。
- **\$\\text{Dist}\$（切比雪夫距离衰减）**：距离越近的目标基础分值越高，避免全图折返跑。

#### 2. 远程单位走位与“防贴脸”启发式规则

- **远程射击判定**：
  - 若目标已经在当前单位的有效射程区间 \$\[\\text{MinRange}, \\text{MaxRange}\]\$ 内（如距离为 2\~4 格），**AI 移动步数强制为 0（原地架枪射击）**，享受正规军不动暴击加成，且杜绝主动靠近进入 1 格惩罚区。
- **风筝拉扯判定 (Kite Away)**：
  - 若远程单位当前已被敌方近战单位贴身（\$\\text{Dist} = 1\$），AI 评估后方安全格：
    - 若能后撤至安全射程格且不被卡位，优先后撤 1\~2 格再射击。
    - 若四周被卡死无法脱身，才被迫执行削减 50% 伤害的近战攻击。

#### 3. 战略占领决策

- **中央据点踏入**：若当前中央据点无人占领，且某前排高血量 AI 移动力能够正好踩上 `(7, 4)`，优先放弃一次轻微攻击机会，直接移动进驻并启动 5 回合倒计时。
- **幸存者驻地控制**：若附近 3 格内有中立或敌方驻地，低速前排或多余炮灰优先移入驻地进行回合占领。

## 第八章 Three.js 程序化几何体工厂标准 (Procedural Unit Builder)

为了保障项目能被大语言模型一次性自动化生成并独立运行，工程严禁引用任何外部 `.gltf`、`.fbx` 或 `.obj` 资产包，所有 3D 模型采用 **Three.js 原生几何体拼装（CSG / Composite Mesh）**，结合 Low-Poly 扁平色块风格。

### 8.1 材质与着色规范

- **材质选择**：全场景采用 `MeshLambertMaterial` 或 `MeshToonMaterial`（卡通着色）。
- **光照标准**：
  - 环境光：`THREE.HemisphereLight(0xffffff, 0x444455, 0.7)`，提供柔和暗部泛光。
  - 平行主光：`THREE.DirectionalLight(0xfff5ea, 0.85)`，投射阴影，阴影图分辨率 `1024×1024`，开启 `PCFSoftShadowMap`。

### 8.2 全单位代码拼装清单与层级规范

所有单位以一个空的 `THREE.Group` 作为根节点（Root），原点设在地面接触点 `(0, 0, 0)`，以便于根据网格坐标对齐。

```plaintext
[UnitRoot: Group]
   ├── [BodyMesh: Mesh] (胶囊体/立方体)
   ├── [HeadMesh: Mesh] (球体/圆柱体)
   ├── [FeatureMesh: Mesh] (枪炮/背包/脓包/钩爪)
   └── [OverlayAnchor: Object3D] (血条与状态图标绑节点, y = 1.6)

```

#### 1. 武装平民 (Civilian)

- **躯干**：`CapsuleGeometry(0.35, 0.5, 4, 8)`，淡蓝色牛仔工作服配色 `0x4a90e2`，居中高度 `y = 0.5`。
- **头部**：`SphereGeometry(0.28, 8, 8)`，肉色 `0xffdbac`，`y = 1.05`。
- **装备（球棒）**：`CylinderGeometry(0.05, 0.08, 0.8, 6)`，深褐色 `0x8b5a2b`，斜插在右侧手部，倾角 `45°`。

#### 2. 正规军士兵 (Infantry Soldier)

- **躯干**：`BoxGeometry(0.7, 0.8, 0.5)`，军绿色防弹背心 `0x2e4a2e`，`y = 0.55`。
- **头部（头盔）**：`SphereGeometry(0.32, 8, 8)` 加上半沿扁圆柱，深军绿 `0x1f331f`，`y = 1.15`。
- **装备（自动步枪）**：组合长方体枪身 `BoxGeometry(0.12, 0.15, 0.7)` + 黑色枪管 `CylinderGeometry(0.04, 0.04, 0.3)`，指向正前方。

#### 3. 装甲战斗车 (Armored Vehicle - 2×1 格)

- **履带/底盘**：`BoxGeometry(2.6, 0.45, 1.3)`，装甲铁灰 `0x334155`，`y = 0.25`。
- **车体座舱**：`BoxGeometry(1.8, 0.6, 1.1)`，深海蓝 `0x1e293b`，`y = 0.7`。
- **炮塔**：`CylinderGeometry(0.45, 0.55, 0.4, 8)`，置于车体前段 `y = 1.15`。
- **机炮管**：`CylinderGeometry(0.08, 0.08, 1.4, 8)`，水平延伸，偏转 `90°`。

#### 4. 爬行尸 (Crawler)

- **体态**：极矮贴地结构。躯干 `BoxGeometry(0.5, 0.25, 0.7)`，腐肉绿 `0x4d7c0f`，`y = 0.2`。
- **四肢**：4 个弯曲折线小方块支在四周，呈现断骨爬行姿态。

#### 5. 毒爆尸 (Boomer)

- **主体（巨型圆肚）**：`SphereGeometry(0.75, 8, 8)`，亮酸绿色 `0x84cc16`，放大膨胀，`y = 0.75`。
- **脓包群**：在球体周围随机附着 4\~5 个小球 `DodecahedronGeometry(0.18)`，材质赋为发光黄色 `0xfacc15`。

#### 6. 缝合憎恶 (Abomination - 2×2 格)

- **身躯**：复合两个非对称厚重方块 `BoxGeometry(1.6, 1.5, 1.5)`，灰绿色 `0x2d4a22`，表面带有黑色线缝（Stitches）。
- **巨型右臂（屠夫铁钩）**：弯曲圆环几何体切片 `TorusGeometry(0.4, 0.1, 6, 12, Math.PI)`，挂载金属银色 `0x94a3b8`。

## 第十章 卡牌抽取与手牌管理机 (CardHandManager)

《命运防线》的卡牌系统并非传统 CCG 的牌库循环疲劳战，而是作为战棋玩法的“战场精准投放凭证”。本模块定义卡组构成、手牌上限、动态补牌及拖拽投射的核心规范。

```plaintext
[回合开始] ──► [清点当前手牌数 (N)] ──► [从阵营卡池补齐至 4 张]
       │
       ▼
[玩家交互: 悬停预览/点击或拖拽] ──► [校验资源点是否充足]
       │ 满足
       ▼
[射线投射至网格] ──► [校验地块合法性 (本方部署线 & 空置)]
       │ 合法
       ▼
[扣除对应点数] ──► [手牌离场销毁] ──► [网格实例化 3D 实体棋子]

```

### 10.1 牌组与抽牌规则

1. **战前卡池（Faction Card Pool）**：
   - 玩家卡池由当前阵营已解锁的所有兵种构成（共 5\~7 种）。
   - 牌库采用“无尽权重随机池（Weighted Infinite Pool）”设计，不设摸空弃牌堆，防止战棋大后期无兵可出的僵局。
2. **权重概率分布**：
   - 低阶单位（1\~2 点）：单次抽取基础权重 50%
   - 中阶单位（3\~4 点）：单次抽取基础权重 35%
   - 高阶/英雄单位（6\~8 点）：单次抽取基础权重 15%
3. **手牌槽位与补牌逻辑**：
   - **手牌上限**：固定为 **4 张**。
   - **补牌时机**：每个大回合开始、自然增长资源发放完毕后，系统自动清点手牌数量 \$N\$。若 \$N &lt; 4\$，则立即从卡池中随机补发 \$4 - N\$ 张卡牌入手。
   - **溢出处理**：手牌已满 4 张时不补牌，不设爆牌惩罚。

### 10.2 卡牌实体与交互状态机

每张卡牌在 UI 容器中拥有 5 种互斥的视觉与交互状态：

```plaintext
[Normal] ──(鼠标悬停)──► [Hovered] ──(按下并移动)──► [Dragging]
   ▲                       │                             │
   │ (取消拖拽/点空)        ▼                             ▼
   └────────────────── [Selected] ◄────────────── [Targeting]

```

- **Normal（常态）**：卡牌以轻微扇形排布于屏幕底部，高度露出 80%，显示费用、名称及微缩图腾。
- **Hovered（悬浮）**：卡牌向上浮动 24px，缩放至 1.08 倍，边框泛白光，展开显示完整攻防属性、射程与技能词条。
- **Dragging / Targeting（拖拽与网格寻靶）**：
  - 卡牌脱离底部栏跟随指针，半透明度设为 0.75。
  - 场景控制器启动屏幕射线（Raycaster），对地表网格进行高频检测：
    - **合法目标格**（己方部署线且无遮挡）：地块浮起绿色外发光脉冲框，卡牌下方显示 3D 实体虚影（Ghost Mesh）。
    - **非法目标格**（越界/敌方区域/已被占用）：地块显示红色警示框，禁止放置。
- **Deployed（成功施放）**：扣除费用，卡牌原地化为光点粒子消散，地块上的虚影伴随轻微弹性落地震动变为实体。
- **Canceled（回弹重置）**：拖拽至非法区域松手时，卡牌通过平滑贝塞尔曲线（GSAP Tween）瞬间归位回到底部手牌栏。

为保证开发高效性与文本渲染的高清晰度，本项目严格遵循“3D 场景与网格交互全归 WebGL，文本信息流与交互控件全归 DOM / Tailwind CSS”的双层挂载模型。

### 11.2 世界坐标向屏幕 UI 投影 (3D-to-2D Projection)

每个单位头顶的血条与 Buff 标记不使用 WebGL 贴图制作，而是由 DOM 元素统一托管在 `#floating-hud-container`，并在每帧渲染循环中将单位世界坐标实时映射至屏幕像素坐标：

\$\$\\begin{aligned} \\mathbf{V}\_{clip} &amp;= \\mathbf{V}\_{world} \\times \\mathbf{M}\_{view} \\times \\mathbf{M}\_{proj} \\\\ X\_{screen} &amp;= \\left(\\frac{\\mathbf{V}\_{clip}.x + 1}{2}\\right) \\times \\text{ScreenWidth} \\\\ Y\_{screen} &amp;= \\left(\\frac{-\\mathbf{V}\_{clip}.y + 1}{2}\\right) \\times \\text{ScreenHeight} \\end{aligned}\$\$

- **优化准则**：
  - 当单位未发生移动且相机静止时，缓存投影矩阵计算，避免逐帧重复触发布局重排（Reflow）。
  - 视锥体外部剔除：若 \$\\mathbf{V}\_{clip}.z &lt; -1\$ 或 \$&gt; 1\$，立即赋予 DOM 元素 `display: none`。

### 12.2 Web Audio API 程序化合成音效协议 (Sound System)

为确保游戏在单文件运行或纯前端断网环境下依然拥有丰富音效，音效系统内置基于 `AudioContext` 实时调制的合成发生器，彻底摆脱外部 `.mp3/.wav` 音频文件的网络依赖与加载失败风险。

TypeScript

```plaintext
// src/audio/SoundSynthesizer.ts
export class SoundSynthesizer {
  private static ctx: AudioContext | null = null;

  private static initContext() {
    if (!this.ctx) {
      this.ctx = new (window.AudioContext || (window as any).webkitAudioContext)();
    }
  }

  /**
   * 触发战斗事件音效
   */
  public static play(event: 'DEPLOY' | 'SHOOT' | 'HIT' | 'EXPLODE' | 'CAPTURE' | 'VICTORY') {
    this.initContext();
    if (!this.ctx) return;

    const t = this.ctx.currentTime;
    const osc = this.ctx.createOscillator();
    const gain = this.ctx.createGain();
    osc.connect(gain);
    gain.connect(this.ctx.destination);

    switch (event) {
      case 'DEPLOY': // 棋子落盘微缩塑料碰撞音
        osc.type = 'triangle';
        osc.frequency.setValueAtTime(320, t);
        osc.frequency.exponentialRampToValueAtTime(80, t + 0.08);
        gain.gain.setValueAtTime(0.3, t);
        gain.gain.linearRampToValueAtTime(0, t + 0.08);
        osc.start(t);
        osc.stop(t + 0.08);
        break;

      case 'SHOOT': // 紧凑枪声
        osc.type = 'square';
        osc.frequency.setValueAtTime(880, t);
        osc.frequency.exponentialRampToValueAtTime(110, t + 0.12);
        gain.gain.setValueAtTime(0.2, t);
        gain.gain.linearRampToValueAtTime(0, t + 0.12);
        osc.start(t);
        osc.stop(t + 0.12);
        break;

      case 'EXPLODE': // 低频毒爆殉爆重低音
        osc.type = 'sawtooth';
        osc.frequency.setValueAtTime(120, t);
        osc.frequency.exponentialRampToValueAtTime(20, t + 0.4);
        gain.gain.setValueAtTime(0.5, t);
        gain.gain.linearRampToValueAtTime(0, t + 0.4);
        osc.start(t);
        osc.stop(t + 0.4);
        break;

      case 'CAPTURE': // 据点占领脉冲音
        osc.type = 'sine';
        osc.frequency.setValueAtTime(440, t);
        osc.frequency.exponentialRampToValueAtTime(880, t + 0.25);
        gain.gain.setValueAtTime(0.25, t);
        gain.gain.linearRampToValueAtTime(0, t + 0.25);
        osc.start(t);
        osc.stop(t + 0.25);
        break;
    }
  }
}

```
